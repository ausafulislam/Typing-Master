## About the Project

TypeMaster is a typing speed and accuracy testing game with a bold, brutalist design. It challenges users to type given text as fast and accurately as possible, calculates their words-per-minute (WPM) and accuracy in real time, and ranks them against other players on a live global leaderboard.

The game is built for anyone who wants to improve their typing speed while competing for a top spot on the leaderboard. It combines a clean, distraction-free typing interface with instant performance feedback, making every test feel fast, competitive, and satisfying.

## What Makes It a Good Game

- **Instant feedback** — WPM and accuracy update live as you type, no waiting for results.
- **Competitive edge** — a real-time leaderboard pushes players to beat their own and others' scores.
- **Brutalist design** — a stripped-down, high-contrast interface keeps full focus on typing, not clutter.
- **Fair scoring** — accuracy and speed are both tracked, rewarding precision as much as raw speed.
- **Fast sessions** — each test is quick to start and quick to finish, perfect for a quick skill check or a competitive streak.

## Tech Stack

Built with Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, and Supabase for the leaderboard, deployed on Vercel.
